The objective of this lab was to learn and implement Java inheritance. To do so, we would use JUnit 4 to create and run basic unit tests on our system. We also wanted to get introduced to GitHub codespace as well as use other related tools to learn more about the Java basics. We were tasked to design a hybrid vehicle class that unites both our gasoline and electric vehicle inheritance classes. Then we had to run our unit tests to make sure that everything worked as intended.

My solution was split into two folders. In folder one (named c), I had my source code spread across four different files. The files included "GasolineInterface.Java" which gave me calcGasMPG() and the gas cost data (setCostperGallon). The next file was "ElectricInterface.java" which did the same as the gasoline interface, but calculated for the electric usage and cost data(setCostperKwH). "HybridVehicle.Java" implemented both the electric and gasoline interfaces. This class held the miles, gallons, electric miles, KwH, and what each costed per unit; this is where the calculation data was computed. "CarRunner.Java" implemented the three scenarios that "HybridVehicle.Java" calculated for, which gave the fully gas, fully electric, and hybrid car statistics. Lastly, folder 2 was named "u" and contained the test code for the public methods of Hybrid Vehicle. 

I originally had all the source code in one file, but this was not working due to only one public top-level type being allowed per Java file. After searching online I came to the conclusion of splitting the file into four parts.

The test code uses JUnit4's "@Test" annotation and "assertEquals". This allows the method to be detected as a test instead of a random public method. AssertEquals allowed me to verify that my answers were yielding the correct numbers.  

In conclusion, this lab allowed me to learn basic Java principles such as public methods and unit testing; as well as inheritance and class levels. Inheritance showcased that a single class can satisfy two different roles (Gas and Electric Interfaces) without a hitch. It also allowed me to learn about unit tests and how to let our tests be detected. The final solution computes gasoline miles per gallon, eletric miles per gallon(electricity), and yielded a hybrid version of the two.
